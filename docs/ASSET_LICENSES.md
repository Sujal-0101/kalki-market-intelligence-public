# Visual asset licenses

Phase 16 uses no third-party visual assets.

The Kalki mark, favicon, social-preview composition, observatory, pipeline diagram,
status glyphs, and all other illustrations are original repository-native SVG/CSS
work created for this project. They inherit the repository's license. The social
preview PNG is a local rasterization of `social-card.svg`. System font stacks are
used; no web font is downloaded or requested from a third party.
